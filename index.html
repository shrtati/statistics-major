Week 2: SQL Data Extraction & Filtering
  • Query Active Customer Cohorts
    Step-by-Step Exercise:
    1. Load your retail CSV into a SQLite database using Python: df.to_sql('retail', conn).
    2. Write a SQL query to isolate customers who purchased in the last 30 days and spent over $100.
    SELECT CustomerID, COUNT(InvoiceNo) AS OrderCount, SUM(Quantity * UnitPrice) AS TotalSpend
    FROM retail
    GROUP BY CustomerID
    HAVING TotalSpend > 100;
    🔗 Course: Google Advanced Data Analytics (SQL module)

MONTH 2: Linear Regression & Drivers Analysis

Week 5 & 6: Applied Regression Modeling
  • Predict Customer Spending
    Step-by-Step Exercise:
    1. Set your target variable ($Y$) = TotalSpend.
    2. Set predictors ($X$) = OrderCount, AvgBasketSize, and DaysSinceLastPurchase.
    3. Fit a Linear Regression model using statsmodels in Python or R.
    import statsmodels.api as sm
    X = df[['OrderCount', 'AvgBasketSize']]
    y = df['TotalSpend']
    model = sm.OLS(y, sm.add_constant(X)).fit()
    print(model.summary())
    🔗 Course: Business Statistics (Rice University) 🔗 Video: Linear Regression Simply Explained

    "Alumni Insight: Stakeholders won't ask for your p-values. They want to know: 'Should we run a campaign to increase purchase frequency or increase basket size?'"

🩺 Path 2: Biostatistics & Clinical Research

Role Simulated: Biostatistician / Clinical Data Scientist

MONTH 1: R/SAS Foundations & Clinical Datasets

Week 1: R Studio & Data Types
  • Install RStudio & Load Heart Failure Data
    Step-by-Step Exercise:
    1. Install R and RStudio Desktop (free open source).
    2. Download the Heart Failure Clinical Records CSV from UCI.
    3. Run the following script:
    data <- read.csv("heart_failure_clinical_records_dataset.csv")
    str(data)
    summary(data$age)
    🔗 Dataset: UCI Heart Failure Data 🔗 Video: R Programming Tutorial for Beginners
Week 2: Clinical Baseline Characteristics
  • Generate "Table 1" (Clinical Baseline)
    Step-by-Step Exercise:
    1. In clinical trials, Table 1 always compares baseline patient characteristics (Age, Gender, Blood Pressure) across groups.
    2. Use the R package table1 to automatically build this standard medical publication table.
    install.packages("table1")
    library(table1)
    table1(~ age + ejection_fraction + serum_creatinine | high_blood_pressure, data=data)
    "Alumni Insight: Table 1 is required in almost every clinical trial paper submitted to regulatory bodies like the FDA."
Week 3 & 4: Hypothesis Testing & Normality Checks
  • Run T-Tests and Chi-Square Tests
    Step-by-Step Exercise:
    1. Test if age differs significantly between patients who survived vs. deceased: t.test(age ~ DEATH_EVENT, data=data).
    2. Test association between high blood pressure and mortality using Chi-Square: chisq.test(data$high_blood_pressure, data$DEATH_EVENT).
    🔗 Course: Improving Statistical Inferences (TU Eindhoven)

MONTH 2: Survival Analysis & KM Curves

Week 5 & 6: Construct Kaplan-Meier Curves
  • Fit Survival Models in R
    Step-by-Step Exercise:
    1. Install R packages survival and survminer.
    2. Define the survival object using follow-up time (time) and status (DEATH_EVENT).
    3. Plot survival probability over time split by high blood pressure status.
    library(survival)
    library(survminer)
    fit <- survfit(Surv(time, DEATH_EVENT) ~ high_blood_pressure, data = data)
    ggsurvplot(fit, data = data, pval = TRUE)
    🔗 Video: Survival Analysis & Kaplan Meier in R
Week 7 & 8: Log-Rank Testing & Cox Regression
  • Evaluate Hazard Ratios
    Step-by-Step Exercise:
    1. Execute a Log-Rank test to get the p-value comparing patient survival curves.
    2. Fit a Cox Proportional Hazards model to adjust for confounding variables (age, serum sodium).
    cox_model <- coxph(Surv(time, DEATH_EVENT) ~ age + high_blood_pressure + ejection_fraction, data = data)
    summary(cox_model)
    "Alumni Insight: Cox models allow biostatisticians to isolate the effect of a treatment while controlling for pre-existing medical conditions."
