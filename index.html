MONTH 2: Linear Regression & Driver Analysis

Week 5 & 6: Run Linear Regression
  • Day 1-2: Regression Theory & Video
    Watch video on Ordinary Least Squares (OLS) regression concepts.
    🔗 Video: Linear Regression Simply Explained
  • Day 3-4: Fit OLS Model in Python
    Regress TotalSpend ($Y$) against Frequency and AvgBasketSize ($X$).
    import statsmodels.api as sm
    X = df[['Frequency', 'AvgBasketSize']]
    y = df['TotalSpend']
    model = sm.OLS(y, sm.add_constant(X)).fit()
    print(model.summary())
  • Day 5: Check Model Assumptions
    Plot residual plots to check for linearity and homoscedasticity.
Week 7 & 8: Business Interpretation

🩺 Path 2: Biostatistics & Clinical Research

Goal: Calculate patient survival rates and drug safety under scientific rigor.

MONTH 1: R Studio & Clinical Tables

Week 1: Setup & Environment
  • Day 1: Install R and RStudio
    Download R language engine and RStudio Desktop. Verify basic console commands.
    🔗 Video: R Programming Tutorial
  • Day 2: Download Medical Dataset
    Get Heart Failure Clinical Records dataset from UCI repository.
    🔗 Dataset: UCI Heart Failure Data
  • Day 3: Read CSV in R
    Import data script and run basic summary functions.
    data <- read.csv("heart_failure_clinical_records_dataset.csv")
    str(data)
    summary(data)
  • Day 4: Vector Manipulation
    Practice filtering vectors: extract ages of deceased patients vs. surviving patients.
  • Day 5: Save R Script
    Push R script to GitHub.
Week 2: Generate Baseline "Table 1"
  • Day 1-2: Install table1 Package
    Learn standard clinical formatting for baseline cohort characteristics.
  • Day 3-5: Generate Baseline Summary
    Build publication-ready baseline table grouped by blood pressure status.
    library(table1)
    table1(~ age + ejection_fraction + serum_creatinine | high_blood_pressure, data=data)
Week 3 & 4: Hypothesis Testing
  • Day 1-3: Perform T-Tests
    Test if mean age differs significantly between survival outcome groups.
    t.test(age ~ DEATH_EVENT, data=data)
  • Day 4-5: Perform Chi-Square Test
    Evaluate association between high blood pressure and mortality rate.

MONTH 2: Survival Analysis & KM Curves

Week 5 & 6: Construct Kaplan-Meier Curves
  • Day 1-2: Learn Survival Analysis Math
    Watch video tutorial on Kaplan-Meier estimation and hazard rates.
    🔗 Video: Survival Analysis in R
  • Day 3-5: Fit KM Model & Plot
    Construct survival curves comparing high blood pressure vs normal pressure groups.
    library(survival)
    library(survminer)
    fit <- survfit(Surv(time, DEATH_EVENT) ~ high_blood_pressure, data = data)
    ggsurvplot(fit, data = data, pval = TRUE)
Week 7 & 8: Log-Rank Testing & Cox Regression
  • Day 1-3: Run Log-Rank Test
    Calculate p-value to determine if survival differences are statistically meaningful.
  • Day 4-5: Fit Cox Regression Model
    Adjust for confounders (age, ejection fraction) using Cox Proportional Hazards.
